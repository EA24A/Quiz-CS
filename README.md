## 📖 Overview
A multi-question CLI quiz application built to practice programming fundamentals, 2D arrays, user input validation, and score calculation in modern C#. The quiz features questions regarding general knowledge and the IT curriculum at BKTM.

---

## ✨ Features
- **Interactive Question Flow:** Console-based multiple-choice evaluation with input prompts.
- **Score Tracking:** Live score counter providing final evaluation and feedback upon completion.
- **Data Structures:** Multi-dimensional arrays mapping questions, answer options, and correct solutions.

- **Language:** C#
- **Runtime:** .NET 8
